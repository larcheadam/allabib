# تطبيق البوابة المدرسية الرقمية "مؤسسة اللبيب" (Etablissement Allabib PWA)

تطبيق ويب تقدمي متطور (PWA) بلغات متعددة (العربية والفرنسية) لإدارة الحصص الدراسية، توزيع الاستعمالات الزمنية، تتبع الغياب واستدعاءات أولياء الأمور، ومشاركة الموارد الرقمية المرفوعة سحابياً.

---

## 1. الهوية البصرية والألوان (Branding & Palette)
تم استخلاص الألوان والخطوط مباشرة من شعار المؤسسة الرسمي المرفق:
- **الأزرق الداكن (Navy Blue):** `#1E3A8A` (اللون الأساسي للترويسة والمكونات الرئيسية)
- **الأزرق السماوي (Sky Blue):** `#0EA5E9` (اللون التفاعلي للأزرار والروابط النشطة)
- **البرتقالي/الذهبي (Amber):** `#F59E0B` (لون التحذيرات، تنبيهات استدعاءات أولياء الأمور، والنصوص الثانوية للشعار)
- **الأحمر والنسق اللوني للغياب (Danger):** `#EF4444` (لتسجيل الغياب وتنبيهات الإلغاء)
- **الأخضر (Success):** `#10B981` (لتأكيد العمليات والحضور بنجاح)
- **الخلفية المريحة (Background):** `#F8FAFC`

## 2. متطلبات التشغيل والتهيئة (Setup & Configurations)

### أ. تهيئة قاعدة البيانات (Supabase Database Setup)
1. قم بإنشاء مشروع جديد في منصة [Supabase](https://supabase.com).
2. افتح محرر الاستعلامات (SQL Editor) في لوحة تحكم Supabase الخاصة بك.
3. انسخ محتوى الملف [`schema.sql`](file:///e:/allabib/schema.sql) والصقه في محرر الاستعلامات، ثم قم بتشغيله (Run).
4. سيقوم هذا الملف بإنشاء:
   - كافة الجداول اللازمة (`profiles`, `levels`, `classes`, `subjects`, `timetables`, `session_substitutions`, `attendance`, `parent_summons`, `resources`, `notifications`, `school_holidays`).
   - دالة وتريغر `check_timetable_conflicts` لمنع تعارض الحصص (فحص تداخل الأستاذ، القاعة، والقسم تلقائياً على مستوى قاعدة البيانات).
   - تفعيل جدار الحماية وسياسات الأمن على مستوى الصفوف (RLS Policies) لكل الأدوار (Admin, Teacher, Student).

### ب. تهيئة رفع الملفات (Cloudinary Setup)
1. قم بإنشاء حساب على منصة [Cloudinary](https://cloudinary.com) واستخدم اسم السحابة المحدد للمشروع: `ilbpvbdc`.
2. اذهب إلى **الإعدادات (Settings)** ← **الرفع (Upload)** ← **إضافة إعداد رفع مسبق غير موقع (Add upload preset)**.
3. قم بتهيئة الإعداد كالتالي:
   - **وضع التوقيع (Signing Mode):** غير موقع (Unsigned).
   - **الاسم (Upload preset name):** `allabib_preset` (تأكد من مطابقة الاسم مع المتغير `CLOUDINARY_UPLOAD_PRESET` في ملف [`app.js`](file:///e:/allabib/app.js)).
   - **الامتدادات المسموح بها (Allowed formats):** `pdf`, `jpg`, `png`, `jpeg`
   - **الحد الأقصى لحجم الملف:** 10 ميغابايت (10MB).
   - **المجلد المستهدف:** `allabib/resources`

### ج. إعداد المتغيرات في الواجهة الأمامية (Frontend Configuration)
ملف الإعدادات المطور [`app.js`](file:///e:/allabib/app.js) يحتوي بالفعل على المفاتيح العامة والروابط المحددة بشكل جاهز للعمل:
```javascript
const SUPABASE_URL = "https://pfyhjbwqtiuchkmnlgaf.supabase.co";
const SUPABASE_PUBLISHABLE_KEY = "sb_publishable_lkR8CKbCS_GKX0a5AodCuQ_od_v4_WQ";
const CLOUDINARY_CLOUD_NAME = "ilbpvbdc";
const CLOUDINARY_UPLOAD_PRESET = "allabib_preset";
```
*ملاحظة أمنية:* بما أن التطبيق عبارة عن واجهة أمامية ثابتة (Static PWA) يتم استضافتها لدى العميل، فإن هذه المفاتيح عامة وآمنة تماماً للنشر طالما أن سياسات RLS مفعلة في قاعدة البيانات. لا تقم أبداً بكتابة المفتاح السري (Secret Key) الخاص بـ Supabase في هذا التطبيق.

## 3. مميزات وخصائص التطبيق (Key Features)

### 1. نظام منع تعارض الحصص المزدوج (Double Conflict Prevention)
يتم التحقق من تعارض الجداول الزمنية على مستويين:
- **مستوى العميل (Client-Side Check):** تقوم الدالة `checkTimetableConflict` في ملف [`app.js`](file:///e:/allabib/app.js) بفحص تداخل الوقت لحظياً عند محاولة المسؤول إضافة حصة جديدة في الاستعمال الزمني.
- **مستوى الخادم/قاعدة البيانات (Database-Side Check):** يضمن التريغر المبرمج في ملف [`schema.sql`](file:///e:/allabib/schema.sql) إرجاع خطأ فوري ومنع الإدخال إذا تم محاولة الالتفاف على الواجهة أو حدوث تعارض متزامن.

### 2. تسجيل الدخول السريع عبر بطاقات الهوية الرقمية (QR Code Login)
- يمكن للمسؤول (Admin) توليد بطاقة رقمية لأي تلميذ أو أستاذ تحتوي على رمز QR فريد مطبوع.
- يقوم رمز الـ QR بحفظ كود التشفير وصيغة الدخول المباشر الآمن بصيغة `allabib_auth:{email}:{password}`.
- عند مسح الرمز عبر كاميرا التطبيق في صفحة الدخول، يتم فك الترميز وتسجيل الدخول بشكل فوري عبر Supabase Auth دون الحاجة لكتابة البيانات يدوياً.

### 3. دعم اللغات والتوجيه التلقائي (Bilingual Translation & LTR/RTL)
- يدعم التطبيق التبديل اللحظي بين اللغتين **العربية (RTL)** كخيار افتراضي و **الفرنسية (LTR)**.
- عند التبديل، يتم تغيير ترميز الصفحة واتجاهات العناصر والتخطيطات بالكامل لضمان أفضل تجربة مستخدم متناسقة.

## 4. خطوات النشر والاستضافة (Vercel Deployment)

لتشغيل ونشر التطبيق على استضافة Vercel:
1. قم بتثبيت واجهة Vercel CLI أو ربط مستودع GitHub الخاص بك بمنصة [Vercel](https://vercel.com).
2. تأكد من وجود الملفات التالية في نفس المجلد الجذري:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `sw.js`
   - `manifest.json`
   - `vercel.json`
   - `logo.svg`
3. قم بتشغيل الأمر التالي للنشر الفوري:
   ```bash
   vercel
   ```
4. بعد التحقق من نجاح النشر التجريبي، قم بالترقية للإنتاج:
   ```bash
   vercel --prod
   ```

سيتكفل الملف [`vercel.json`](file:///e:/allabib/vercel.json) تلقائياً بضبط إعدادات التخزين المؤقت لملف الخدمة (Service Worker) لتجنب كاش المتصفح القديم وضمان وصول التحديثات الفورية للمستخدمين، مع تمكين ميزات تشغيل التطبيق دون اتصال بالإنترنت (Offline Capability).
